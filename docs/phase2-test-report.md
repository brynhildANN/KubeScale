## 过程与限制

- 初次浏览器脚本误选隐藏标签页 canvas，并使用了与默认确认框不一致的按钮名称；已修正选择器、明确删除按钮中文文案，完整流程随后通过。检查截图时发现低比例 CPU 刻度取整及目标线超出纵轴范围，已修复并复验。
- 宿主机没有 C 编译器，竞态检测改用已有 Go 容器；旧构建目录权限不一致，生产构建输出改为独立临时目录；文件监听数量不足时使用轮询监听启动测试前端。
- 未执行长期稳定性、完整 k6 性能基准、所有外部控制器识别或共享网络部署验收。暂停不取消已开始的协调，历史曲线对已删除 Pod 的覆盖限制保持明确记录，详见[实现说明](phase2-implementation.md)。
